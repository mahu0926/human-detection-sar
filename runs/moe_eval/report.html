Setup and caveats

  • maritime: best_seabornsee.pt
  • urban: best.pt
  • vegetation: heridal_random_best.pt
  • Test images per terrain: maritime 774, urban 365, vegetation 157.
  • Every expert sees the original full-resolution image, resized to 640px by YOLOv5. The gate sees a 224px crop.
  • If a test image was in an expert's training split, that expert's numbers are optimistic. Check that the test folders match each expert's held-out split.
  • Oracle routing is the best any gate could do with these experts. The gap between MoE and oracle is the cost of routing mistakes.
  • All 3 experts + NMS runs every expert on every image (3× the compute). If MoE matches or beats it, routing is worth it.
